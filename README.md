# Task 1

Программа для обработки бинарного файла, содержащего последовательность 32-битных беззнаковых целых чисел в формате Big Endian.

Для входного файла вычисляются:

- сумма всех чисел (с использованием длинной арифметики Python);
- минимальное значение;
- максимальное значение.

Запуск

```powershell
python3 calc_data.py <path_to_file>
```

## Использованные оптимизации

### NumPy

Данные обрабатываются с помощью NumPy, что позволяет выполнять вычисления в нативном коде без перебора элементов в Python.

### Memory Mapping (mmap)

Для доступа к данным используется mmap, что уменьшает накладные расходы на чтение файла.

### Multiprocessing

Файл разбивается на независимые диапазоны, которые обрабатываются параллельно несколькими процессами.

## Генерация тестовых данных

### Для проверки корректности решения были созданы следующие тестовые файлы:

- t1_basic.bin: Проверка базовой логики вычислений
- t2_endian.bin: Проверка корректной обработки Big Endian
- t3_large_sum.bin: Проверка вычисления больших сумм
- t4_random.bin: Случайные данные
- t5_2gb.bin: Производительный тест размером 2 ГБ

## Результаты замеров

Замеры производительности выполнялись на тестовом файле размером 2 ГБ (t5_2gb.bin).

| Версия | Время |
|---------|---------|
| Базовая реализация (read + NumPy) | 7.15 s |
| mmap + NumPy | 4.20 s |
| mmap + multiprocessing | 3.79 s |

## Docker

Сборка контейнера:

```bash
docker build -t calc_data .
```

Запуск (Linux/macOS):

```bash
docker run --rm -v /path/to/data:/data:ro calc_data /data/t1_basic.bin
```

Запуск (Windows PowerShell):

```powershell
docker run --rm -v "${PWD}:/data:ro" calc_data /data/t1_basic.bin
```
